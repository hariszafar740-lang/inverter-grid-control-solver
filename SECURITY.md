# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.2.x` (`main`) | Yes |
| `< 0.2.0` | No |

## Reporting a Vulnerability

Please report suspected security issues via GitHub Private Vulnerability Reporting on `hariszafar740-lang/inverter-grid-control-solver` rather than opening a public issue. Include a minimal reproduction script and Python version details.
